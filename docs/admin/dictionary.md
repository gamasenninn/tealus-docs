# 業務辞書（自己成長辞書）

社内の固有名詞（人名・メーカー名・型番・業務用語）は、音声認識や画像 OCR で**必ず崩れます**。「上山」が「神山」に、「アンプリ」が「アンプリー」になる、といった崩れです。

Tealus は **崩れた表記（別名）→ 正しい表記（正規名）** の対応表を持ち、文字起こしと AI エージェントの両方に効かせます。この対応表は、**人が文字起こしを直した履歴から自動で育ちます**（v0.5.0、[#327](https://github.com/gamasenninn/tealus/issues/327)）。

!!! info "「勝手に覚える」わけではありません"
    自動学習した別名は、**すぐには効きません**。いくつかのゲートを通過して初めて実際の変換に使われます（後述）。誤った別名が入ると全社の文字起こしが壊れるため、**入りやすさより正しさを優先**した設計です。

## 3 つの供給元（precedence）

辞書の 1 行 1 行が「どこから来たか」（`source`）を持ち、衝突したときは次の優先順位で解決されます。

| source | 供給元 | 優先度 |
|---|---|---|
| `manual` | 管理画面で人が登録・編集したもの | **最優先** |
| `auto` | 文字起こしの編集履歴から自動学習したもの | 中 |
| `organon` | [organon](../concepts/organic-ontology.md)（別リポジトリの組織オントロジー）から取り込んだもの | 低 |

!!! tip "organon がなくても辞書は機能します"
    v0.7.0（[#348](https://github.com/gamasenninn/tealus/issues/348)）から、辞書テーブルの内容が `dictionary.local.ttl` として発行され、AI エージェントはこれを優先して読みます。**organon を導入していない環境でも、`manual` + `auto` だけで語彙の正規化が生き続けます。**

## 自動学習の流れ

```
AI の文字起こし  vs  人が直した文字起こし
        ↓ 差分から「崩れ → 正しい表記」の組を抽出
   安価ゲート（書き込み前）
     ・読みが 3 モーラ未満は除外（短すぎる別名は過補正のもと）
     ・崩れと正規名の「音」が離れすぎているものは除外
        ↓ 通過したものだけ
   pending（累積中・まだ変換には使われない）
        ↓ 昇格ゲート
   corpus-precision（直された回数 ÷ 全文字起こしでの出現回数）が 0.5 以上
        ↓
   active（ここで初めて実際の変換に効く）
```

- **`pending` の間は変換に一切使われません。** 補正は `active` の行だけを引くため、間違った候補が溜まっていても実害が出ません
- **1 回直しただけでは昇格しません。** 単発の修正では「たまたま直した」のか「いつも崩れる」のかを区別できないためです。同じ崩れが繰り返し直されて初めて `active` になります
- **却下した別名は復活しません**（`rejected` は墓標として残り、再取り込みでも戻りません）
- 崩れ側の読みは **pykakasi** で推定します。音声認識の崩れは漢字の誤変換が多く、そのままでは読みが取れないためです（そのため **Whisper / Qwen どちらのエンジンの崩れでも同じように扱えます**）

## 管理画面での育成

管理ダッシュボード（`/admin`、アプリの **プロフィール → 管理ダッシュボード**）の「**辞書育成**」タブで、学習された候補をレビューできます。`/system` のダッシュボードではありません。

| 操作 | 内容 |
|---|---|
| 一覧 | 別名の候補を状態（`pending` / `active` / `rejected`）つきで表示 |
| 承認 | 候補を `active` に昇格（自動昇格を待たずに効かせる） |
| 却下 | `rejected` にする（以後、自動学習でも復活しません） |
| 正規名の追加・編集 | 正規名そのものと、分類・読みを編集 |

!!! warning "辞書タブが 500 になるときは migration 忘れです"
    辞書テーブル（`023`〜`025`）が未適用のまま起動すると、**サーバーはクラッシュせず起動してしまい、辞書タブだけが 500 になります**。`cd server && npm run migrate` を実行してください。v0.6.0 以降は起動ログに `[migration-check]` の警告が出ます（[#334](https://github.com/gamasenninn/tealus/issues/334)）。

## どこに効くか

| 効く先 | 内容 |
|---|---|
| 音声の文字起こし | 崩れた固有名詞を正規名に補正（[音声メッセージ](../guide/basic/voice.md)） |
| 画像 OCR・帳票読み取り | `VOCAB_INJECT=true` を設定した場合のみ（既定 OFF、[#315](https://github.com/gamasenninn/tealus/issues/315)） |
| AI エージェント | 別名を正規名として解釈できるようになります（「社長」と「桶田さん」を同一人物として扱う等） |

## 関連する設定

| env | 内容 |
|---|---|
| `TRANSCRIPTION_MODE=organon` | 自ホストの音声認識（Qwen3-ASR）の出力を、組織の語彙で補正する 2 段構成に切り替えます（v0.5.0、[#326](https://github.com/gamasenninn/tealus/issues/326)）。データを外に出さずに固有名詞を回収したい場合の選択肢です |
| `VOCAB_INJECT` | 業務語彙を AI エージェントの画像 OCR にも効かせます（既定 OFF） |
| `ORGANON_INJECT` | organon の `sql_mapping` を AI エージェントに注入します（既定 OFF、[AIエージェント設定](agent.md)） |
