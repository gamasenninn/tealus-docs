# ユーザー管理

管理者は `/admin`（アプリの **プロフィール → 管理ダッシュボード**）の「ユーザー」タブから管理できます。

## 管理画面へのアクセス

管理者ロール（`admin`）を持つユーザーのみアクセス可能です。

## ユーザー一覧

登録済みのすべてのユーザーが一覧表示されます。

## ユーザーの作成

| 項目 | 説明 |
|---|---|
| ユーザーID | ログインに使用するID（一意） |
| 表示名 | チャットに表示される名前 |
| パスワード | 初期パスワード |
| 権限（ロール） | `admin`（管理者）／ `user`（一般）／ `guest`（ゲスト、下記） |
| AIエージェント | チェックすると Bot ユーザー（`is_bot = true`）として作成 |

### API

```
POST /api/admin/users
```

```json
{
  "login_id": "user001",
  "display_name": "山田太郎",
  "password": "initial_password",
  "role": "user"
}
```

## ユーザーの編集

表示名やロールを変更できます。

### API

```
PUT /api/admin/users/:id
```

## ユーザーの有効化/無効化

ユーザーを削除する代わりに、アカウントを無効化できます。無効化されたユーザーはログインできなくなります。

### API

```
PATCH /api/admin/users/:id/status
```

```json
{
  "is_active": false
}
```

!!! note "Botユーザー"
    AIエージェント用のBotユーザーは `is_bot` フラグで識別されます。作成フォームの「**AIエージェント**」にチェックを入れるか、管理 API に `"is_bot": true` を渡して作れます（**データベースを直接編集する必要はありません**。以前このページはその手順を書いていましたが、古くなっていました）。

## ゲスト（`guest`）

社外の人など、**特定の部屋にだけ参加してもらう**ためのロールです（[#282](https://github.com/gamasenninn/tealus/issues/282)）。

| できないこと | 理由・挙動 |
|---|---|
| 部屋を作る・他の人を招待する | 403 |
| 他の利用者を検索・一覧する | 自分自身しか見えない |
| お知らせ・ポータルリンクを見る | 社内の情報なので空で返す |
| スタンプを作る | 費用がかかり、パックは全員の共有資産のため（送ることはできる）[#495](https://github.com/gamasenninn/tealus/issues/495) |
| `@cc-…` で AI のセッションを起こす | 配送しない（記録だけ残る）[#491](https://github.com/gamasenninn/tealus/issues/491) |
| 社内アシスタントに応答させる | ゲストの投稿には応答しない [#492](https://github.com/gamasenninn/tealus/issues/492) |

!!! warning
    ゲストを部屋に招待するのは、その部屋のメンバー（一般ユーザー・管理者）です。招待した部屋の中の投稿は、ゲストにもすべて見えます。
