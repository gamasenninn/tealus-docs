# ユーザー管理

管理者は `/admin`（アプリの **プロフィール → 管理ダッシュボード**）の「ユーザー」タブから管理できます。

## 管理画面へのアクセス

管理者ロール（`admin`）を持つユーザーのみアクセス可能です。

## ユーザー一覧

登録済みのすべてのユーザーが一覧表示されます。

## ユーザーの作成

| 項目 | 説明 |
|---|---|
| ユーザーID | ログインに使用するID（一意） |
| 表示名 | チャットに表示される名前 |
| パスワード | 初期パスワード（**8 文字以上**。短いと 400） |
| 権限（ロール） | `admin`（管理者）／ `user`（一般）／ `guest`（ゲスト、下記） |
| AIエージェント | チェックすると Bot ユーザー（`is_bot = true`）として作成 |

### API

```
POST /api/admin/users
```

```json
{
  "login_id": "user001",
  "display_name": "山田太郎",
  "password": "initial_password",
  "role": "user"
}
```

!!! note "初回ログインでパスワードの変更を求めます（v0.12.0）"
    管理者が作った人・管理者がパスワードを入れ直した人は、次のログインで「はじめに、パスワードを変えてください」の画面だけが出ます。本人が新しいパスワード（8 文字以上）を決めるまで、ほかの画面は使えません。機械（AIエージェント）と、管理者が自分のパスワードを入れ直したときは求めません。v0.12.0 より前からいる利用者にも求めません。migration `042` が要ります。

## ユーザーの編集

表示名やロール・パスワードの入れ直しができます。編集のときだけ「**社外の窓口**」の印も出ます（下記）。

- 自分自身と、最後の有効なシステム管理者は、無効にも一般にもできません

### 社外の窓口 {#external-contact}

EC サイトのお客様など、**社外の人の発言を代わりに投稿する口座**に付ける印です（v0.12.0）。付けると、その口座が作った部屋は、トーク一覧のタブ「**お客様**」にまとまり、「すべて」「1:1」「グループ」には出なくなります（社内の人が作った部屋に窓口を入れても移りません）。表示の分け方であって、検索や AI の扱いは変えません。migration `045` が要ります（忘れると部屋の一覧が全員 500）。

- 窓口の口座は機械のアカウントですが、**自分が作って今もいる部屋**に限り、社員（ゲスト・機械・窓口以外の有効な人）を後から足せます。それ以外の部屋には人を足せません

## 削除された投稿を戻す {#deleted-messages}

消された投稿の本文は、システム管理者だけが見られる所に残ります（v0.12.0。migration `043`）。管理ダッシュボード（`/admin`）の「**削除された投稿**」に新しい順で 100 件出て、確かめてから「戻す」で元の場所に戻せます。検索・AI など本文を読む口からは、今までどおり見えません。v0.12.0 より前に消したものは戻せません。

## 機械のアカウントとシステム管理者の権限 {#bot-admin-rights}

- 機械（AIエージェント）のアカウントは、メンバーを招待できません（上の「社外の窓口」が自分の部屋に社員を足す場合だけ例外）
- システム管理者は、どのグループでも部屋の管理者と同じ操作（名前・設定・メンバー）ができ、メンバーが残っている部屋も削除できます（確認で残っている人数が出ます）。1 対 1 は対象外で、中身を読めるのは今までどおりメンバーだけです

### API

```
PUT /api/admin/users/:id
```

## ユーザーの有効化/無効化

ユーザーを削除する代わりに、アカウントを無効化できます。無効化されたユーザーはログインできなくなります。

### API

```
PATCH /api/admin/users/:id/status
```

```json
{
  "is_active": false
}
```

!!! note "Botユーザー"
    AIエージェント用のBotユーザーは `is_bot` フラグで識別されます。作成フォームの「**AIエージェント**」にチェックを入れるか、管理 API に `"is_bot": true` を渡して作れます（**データベースを直接編集する必要はありません**。以前このページはその手順を書いていましたが、古くなっていました）。

## ゲスト（`guest`） {#guest}

社外の人など、**特定の部屋にだけ参加してもらう**ためのロールです（[#282](https://github.com/gamasenninn/tealus/issues/282)）。

| できないこと | 理由・挙動 |
|---|---|
| 部屋を作る・他の人を招待する | 403 |
| 他の利用者を検索・一覧する | 自分自身しか見えない |
| お知らせ・ポータルリンクを見る | 社内の情報なので空で返す |
| スタンプを作る | 費用がかかり、パックは全員の共有資産のため（送ることはできる）[#495](https://github.com/gamasenninn/tealus/issues/495) |
| `@cc-…` で AI のセッションを起こす | 配送しない（記録だけ残る）[#491](https://github.com/gamasenninn/tealus/issues/491) |
| 社内アシスタントに応答させる | ゲストの投稿には応答しない [#492](https://github.com/gamasenninn/tealus/issues/492) |

!!! warning
    ゲストを部屋に招待するのは、その部屋のメンバー（一般ユーザー・管理者）です。招待した部屋の中の投稿は、ゲストにもすべて見えます。
