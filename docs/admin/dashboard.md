# ダッシュボード

Tealus のシステムダッシュボード（`/system`）は、管理者がエージェントの設定やシステムの状態を管理するための画面です。

## アクセス

- URL: `/system` パスからアクセス
- 認証: Tealus ServerのJWTを共有（adminロール必須）

## 管理画面は 2 つあります

!!! warning "★ `/system` と `/admin` は別の画面です"
    以前このページは、アクセスログ・ログビューアを `/system` の画面として書いていましたが、**誤りでした**。利用者・Webhook・辞書・アクセスログは、アプリ内の **`/admin`（管理ダッシュボード）** にあります。

| 画面 | 開き方 | 中身 |
|---|---|---|
| **システムダッシュボード**（`/system`） | URL で直接 | 概要 ／ エージェント管理・エージェント設定 ／ ルーム管理（ルームごとの設定） ／ モニタリング（リアルタイム・応答ログ・**サーバーログ**） |
| **管理ダッシュボード**（`/admin`） | アプリの **プロフィール → 「管理ダッシュボード」** | ユーザー ／ Webhook ／ ポータル（ホームのリンク） ／ **アクセスログ** ／ **辞書育成** |

どちらも admin ロールが必要です。

### アクセスログ（`/admin`、[#301](https://github.com/gamasenninn/tealus/issues/301)）

「**最終投稿 / 最終閲覧の集計ビュー**」です。user 単位の運用状況（最後にいつ post したか / 最後にいつ閲覧したか）を一覧化できます。

- 採用者が「ゲスト user の最終 access」を確認する運用に活用
- 将来の Audit log / 採用者保護 trap 分析の基盤として位置付け

## エージェント管理

### エージェント一覧

登録済みのエージェント（Botユーザー）が一覧表示されます。

| 表示項目 | 説明 |
|---|---|
| 表示名 | エージェントの表示名 |
| Login ID | ユーザーID |
| 状態 | 有効/無効バッジ |
| 作成日 | 登録日 |
| ルーム設定 | ルーム個別設定へのリンク |

右上の「グローバル設定」ボタンから、全エージェント共通の設定（`settings.json`・`mcp_config.json`）を編集できます。

### ルーム一覧

エージェントごとに、参加しているルームの一覧が表示されます。

| 表示項目 | 説明 |
|---|---|
| ルーム名 | トークルーム名 |
| タイプ | dm / group |
| メンバー数 | 参加メンバー数 |
| 応答モード | 現在の応答モード |
| 設定 | ルーム個別設定への歯車アイコン |

### ルーム個別設定

各ルームに対して4つのタブで設定を管理します。

#### 基本設定タブ

| 設定項目 | 説明 |
|---|---|
| エージェント有効/無効 | ルームでのエージェント応答の有効/無効 |
| 応答モード | 自動 / 全応答 / メンションのみ / OFF |

!!! note "今の AI（Light v2）が読まない項目はグレーアウトされます（[#590](https://github.com/gamasenninn/tealus/issues/590)）"
    理由が横に表示されます。保存は**次の投稿から反映**され、再起動が要るのはグローバルの MCP 設定だけです。
| 読み上げエンジン ／ 声 | 部屋ごとのエンジン（Aivis / OpenAI / Gemini）と声（v0.10.0 [#444](https://github.com/gamasenninn/tealus/issues/444)）。鍵が未設定のエンジンは選べず、`TTS_PROVIDER` が `browser` / `none` なら効かない旨が出る。アプリ内の ≡ → ルーム設定でも同じ設定ができる |

#### Light プロンプトタブ

Light Agent に対する追加指示をテキストエリアで編集します。ルームごとにエージェントの性格や応答スタイルをカスタマイズできます。

#### Deep プロンプトタブ

Deep Agent（Claude Code）のシステムプロンプト（`CLAUDE.md`）を編集します。

#### MCP設定タブ

ルーム固有の MCP サーバー設定を JSON で直接入力します。

!!! note
    設定の変更は `room_settings.json` に保存されます。

!!! danger "★ 道具が使う鍵は `env` に明示してください（v0.11.0〜）"
    道具（MCP サーバー）は agent-server の環境変数を**受け継がなくなりました**（[#573](https://github.com/gamasenninn/tealus/issues/573)）。以前は書かなくても動いていた API キーや DSN が届かなくなっているので、`env` に `${VAR}` で書いてください。npx で起動する道具は**版を固定**してください（[#577](https://github.com/gamasenninn/tealus/issues/577)）。詳細は [AIエージェント設定 > MCP設定](agent.md#mcp-settings) を参照してください。

## 技術仕様

ダッシュボードは `tealus/dashboard/` にReact + Viteで実装された独立したSPAです。PC向けの設計で、Tealus Server から `/system` パスで静的配信されます。
