# リアクション

メッセージに絵文字でリアクションを付けられます。

## リアクションの付け方

1. メッセージを**長押し**（PCでは右クリック）
2. コンテキストメニュー上部の絵文字パレットから選択

使用可能な絵文字（7 種類）:

| 絵文字 | 意味 |
|---|---|
| ✅ | **完了**（v0.5.0 で追加、[#323](https://github.com/gamasenninn/tealus/issues/323)） |
| 👍 | いいね |
| ❤️ | ハート |
| 😂 | 笑い |
| 🎉 | お祝い |
| 👀 | 確認 |
| 🙏 | お願い・感謝 |

!!! tip "✅ は「完了」の印として使えます"
    👍 は「良い」であって完了ではないため、完了を表す ✅ が先頭に追加されました。

    AI エージェントに「✅ が付いていないものを一覧して」と頼むと、**リアクションの有無で絞り込んで**抽出できます（v0.5.0 [#325](https://github.com/gamasenninn/tealus/issues/325)）。大量のメッセージを読み飛ばして取りこぼす、ということが起きません。

## リアクションの表示

メッセージの吹き出し下部に「絵文字 + 件数」が表示されます（例: 👍 3）。

## リアクションの取り消し

同じ絵文字をもう一度タップすると、リアクションが取り消されます（トグル動作）。
