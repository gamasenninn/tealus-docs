# フォーム（回答フォーム）

ルームに **回答フォーム**を投稿できます（v0.6.0、[#336](https://github.com/gamasenninn/tealus/issues/336)）。選択肢から選んで [回答する] を押すだけで、回答が返信として投稿されます。

「毎日の確認事項に答える」「AI からの質問にまとめて答える」といった、**定型のやりとりの手数を減らす**ための機能です。

## 回答する側の使い方

フォームが投稿されると、チャットの中に選択肢つきのカードとして表示されます。

1. 選択肢を選ぶ（項目によっては補足のテキスト欄が開きます）
2. 自由記述の項目があれば入力する
3. **[回答する]** を押す

押すと、**回答内容が返信としてそのまま投稿されます**。回答の本文にはフォームのタイトルと全項目が読める形で入るので、後から見返したときに「どの質問への回答か」が分かります。

!!! info "一度回答すると、ボタンは締まります"
    回答済みのフォームは、その人にとって入力できない状態になります（v0.6.0 [#341](https://github.com/gamasenninn/tealus/issues/341)）。以前はタイムラインに残ったフォームのボタンが何度でも押せてしまい、グループでは本人以外も多重に押せる状態でした。

## AI エージェントを起こす回答

フォームには **「回答したら特定のエージェントを起こす」** 設定を付けられます。設定されている場合、[回答する] を押すと回答の投稿と同時にそのエージェントが起動します。

つまり回答者から見ると、**「コピペして・手で書いて・別途メンションする」の 3 手が 1 ボタンに畳まれます**。

!!! tip "どの質問への回答かが一意に決まります"
    回答の本文にフォームのタイトルが必ず埋め込まれるため、エージェント側は「どの質問への回答か」を取り違えません。複数の質問が並んでいるときに、自由記述の「様子見」がどちらの項目宛てか分からない、という問題が構造的に起きなくなります。

## フォームを出す側

フォームの投稿は **AI エージェント経由**で行います（専用の画面はありません）。MCP クライアントからは `send_form` ツールを使います。詳細は [MCP Server](../../dev/mcp.md) を参照してください。

- **単一選択（radio）** — 選択肢を並べ、選択時に補足のテキスト欄を出すこともできます
- **自由記述（text）** — 1 行 / 複数行
- **回答時に起こすエージェント** — 省略すると誰も起動しません（単なるアンケート・承認フローとして使えます）

!!! warning "MCP から使う場合はバージョンに注意"
    `send_form` は **tealus-mcp v0.14.8 以降**です。タグを固定して運用している場合は、pin を上げたうえで**クライアントをプロセスごと再起動**してください（再接続だけでは反映されません）。詳細は [MCP Server](../../dev/mcp.md) の注意書きを参照してください。
