# 会話モード（AI と音声で話す）

AI と**声で往復する**画面です（v0.10.0、[#389](https://github.com/gamasenninn/tealus/issues/389) [#405](https://github.com/gamasenninn/tealus/issues/405)）。録音して送る → 文字起こし → 返事を待つ、という普段の音声メッセージと違い、**トランシーバーのように押して話すと、すぐ声で返事が来ます**。壁打ち・考えの整理に向いています。

## 使えるようにする（部屋の管理者）

会話モードは**部屋ごとに開ける**機能で、**既定では閉じています**。

部屋の管理者が、トーク画面右上の **≡** → ルーム設定（管理者）の「**AI と音声で話す**」を「**このルームで開く**」にします。開けていない部屋には、ボタンは 1 つも増えません。

## 話す

1. トーク画面のヘッダーの **マイクのアイコン**（「AI と話す」）を押す
2. 専用の画面が開き、AI につながる
3. 画面下の「**押しながら話す**」ボタンを**押している間だけ**、こちらの声が届きます（離すと AI が答えます）。待っている間は「押しながら話してください」と出ます
4. 画面には今の状態（**聞いています**／**話しています**／**調べています** など）が必ず出ます
5. AI が話している途中でボタンを押すと、**AI の声が止まって割り込めます**

!!! note "話しかけるだけでは届きません"
    会話モードは**押して話す（PTT）方式**です。ボタンを押さずに話しても AI には届きません（以前このページは「そのまま話す」「話しかければ割り込める」と書いていましたが、誤りでした）。

- 人名・機種名など、声では通じにくい言葉は、下の欄（「打って送る」）に**文字で打って送れます**
- 切れたときは「**もう一度つなぐ**」が出ます。**自分から押すまでつなぎ直しません**（使っている間だけ費用がかかるため）
- トランシーバーにつないでいる間・通話中は、ボタンは出ません（音が重なるため）

## 会話は部屋に残りません — 残したいものだけ「このルームに残す」

会話モードのやり取りは、**部屋の投稿にはなりません**（組織の記録に入れずに気軽に話すための入口です）。

良いと思った AI の答えがあったら、**会話の途中で「このルームに残す」**を押してください。その答えが、いま居る部屋に投稿されます（`🎙 会話モードから` の印つき）。残せるのは AI の発言です。

## 知っておくこと

!!! warning "音声は OpenAI の音声対話 API に送られます"
    会話モードは OpenAI の Realtime API（既定 `gpt-realtime-2.1-mini`、管理者が `REALTIME_MODEL` で変更可）を使います。**話した音声そのものが OpenAI に送られます**。普段の音声メッセージ（文字起こしだけを外部に頼む）より外に出るものが多いので、データの扱いに決まりがある組織では、開ける部屋を選んでください。

- AI は、その部屋の指示・業務辞書を踏まえて答えます。部屋ごとに使える道具も管理者が選べます
- 設計と、成立の判断（応答の速さ・割り込みなどの実測）は本体の [08_会話モード設計.md](https://github.com/gamasenninn/tealus/blob/main/docs/08_会話モード設計.md) にあります
