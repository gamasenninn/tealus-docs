# アプリパネル

部屋に登録されたアプリ（社内のシステムなど）を、トーク画面の上のアプリパネルで開けます。登録するのは部屋の管理者です（≡ → ルーム設定の「ルーム設定（管理者）」→「アプリパネル」）。

## 別のタブで開く（v0.12.0） {#new-tab}

PC で広く使うときは、アプリパネルの見出しの **↗ の印（「別のタブで開く」）** を押します。いま選んでいるアプリを別のタブで開きます。

## パスワードを聞かれずに開ける（アプリの通行証、v0.12.0） {#app-pass}

管理者が設定したアプリでは、**部屋のメンバーなら、ベーシック認証のパスワードを打たずに**開けます。ホーム画面のタブのアプリも同じです（「新タブで開く」は除く）。

- 通行証が取れないとき（設定が済んでいない・ゲストなど）は、今までどおりパスワードの箱が出るだけで、壊れはしません
- 部屋を移ると、前の部屋のアプリは閉じます。次の部屋に「自動で開く」アプリがあれば、それを開きます

設定のしかたは [アプリの通行証と「Tealus でログイン」](../../admin/app-pass.md)（管理者向け）を見てください。
