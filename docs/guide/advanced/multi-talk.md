# マルチトーク（PC）

**複数の部屋を 1 画面に並べて**、同時に見たり書いたりできる PC 向けの画面です（`/multi`）。

## 開き方

トーク一覧の上部の **マルチトーク** ボタン（縦の段のアイコン）を押します。**画面の幅が 1024px 以上の端末**でだけ表示されます。

左の部屋の一覧で部屋を押すと、その部屋が**パネル**として開きます。戻るときはツールバーの「**シングルモードに戻る**」です。

## ツールバー

| ボタン | 動き |
|---|---|
| 一覧を隠す ／ 一覧を出す | 左の部屋の一覧を隠して、パネルの場所を広げる |
| タイル整列 | パネルを格子状に並べ直す |
| 横並び整列 | パネルを横一列に並べ直す |
| **すべて最下部へ** | 開いている全パネルを一番下（最新）までスクロール（[#507](https://github.com/gamasenninn/tealus/issues/507)） |
| シングルモードに戻る | 普通のトーク画面へ |

整列のしかた（タイル／横並び）は、次に開いたときも引き継がれます。

## パネルの操作

| 操作 | 動き |
|---|---|
| 見出し（帯）をドラッグ | パネルを動かす。**並びの好きな位置へ差し込めます**（並び順 = 優先度を変えられる、[#515](https://github.com/gamasenninn/tealus/issues/515)） |
| **最小化** | 帯だけにする（帯に部屋の名前が出る）。もう一度押すと元に戻る |
| **最大化** | パネルの置き場いっぱいに広げる。もう一度押すと元の位置と大きさに戻る |
| 帯をダブルクリック | 最小化中なら戻す、それ以外は 最大化 ⇄ 元に戻す（Windows と同じ） |
| ✕ | パネルを閉じる |

([#504](https://github.com/gamasenninn/tealus/issues/504))

## パネルの中の入力欄

パネルは幅が狭いので、**入力欄は畳んだ帯**になっています（[#513](https://github.com/gamasenninn/tealus/issues/513)）。

- 帯には「メッセージを入力…」（書きかけがあれば「下書き: …」）と**マイク**が出ます。音声はすぐ送れます
- 帯を押すと、入力欄が**メッセージの上に重なって大きく開きます**（見ていた位置はずれません）
- 畳んでも書きかけは消えません
