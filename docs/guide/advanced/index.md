# 応用機能

Tealus の応用的な機能を説明します。

- [メッセージ検索](search.md) — キーワードで全ルーム横断検索
- [リアクション](reaction.md) — 絵文字でメッセージにリアクション
- [メンション](mention.md) — @ユーザー名で特定メンバーに通知
- [スタンプ](stamp.md) — AIが自動生成するオリジナルスタンプ
- [TODO機能](todo.md) — メッセージをTODOリストとして管理
- [音声・ビデオ通話](call.md) — WebRTCによるグループ通話・PTT
- [TTS 読み上げ](tts.md) — AIの回答を音声で自動読み上げ
- [フォーム](form.md) — 選択肢や入力欄つきの投稿で回答を集める
- [エージェントの呼び出し口](agent-entry.md) — 自分の投稿をそのまま AI に渡す
- [会話モード（AI と音声で話す）](voice-chat.md) — 電話のように AI と声で往復（部屋ごとに管理者が開ける）
- [マルチトーク（PC）](multi-talk.md) — 複数の部屋を 1 画面に並べる
- [お知らせ](announcement.md) — 公開した投稿を全員のホームに出す

!!! note "ゲストで参加している場合"
    ゲスト（社外の人など）は、部屋を作る・人を招待する・お知らせを見る・スタンプを作ることができず、`@cc-…` や社内アシスタントへの呼びかけにも応答がありません。詳しくは [ユーザー管理 > ゲスト](../../admin/user-management.md#guest) を参照してください。
