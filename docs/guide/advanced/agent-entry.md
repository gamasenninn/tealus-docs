# エージェントの呼び出し口

「アシスタントに聞いたつもりが、メンションを付け忘れていて無反応だった」——この空振りを減らすための入口が用意されています（v0.6.0 [#338](https://github.com/gamasenninn/tealus/issues/338)、v0.7.0 [#354](https://github.com/gamasenninn/tealus/issues/354)）。

メンションを手で打つ方法は従来どおり使えます（[メンション](mention.md)）。ここでは、それ以外の入口を説明します。

## 🤖 ボタン（入力欄）

入力欄の 🤖 ボタンを押すと、**正しい宛先が先頭に入った状態**になります。

- 管理者の場合は**宛先を選ぶピッカー**が開きます（アシスタントのほか、プロジェクト別のエージェントがあればそれも選べます）
- 宛先は横 1 行のスクロールで並ぶため、エージェントが増えても入力欄が圧迫されません

## メッセージを長押し →「エージェントに送る」

**すでに投稿したメッセージ**を、そのままエージェントに渡せます。

音声メッセージの場合は、**文字起こしのテキストが読みやすい形で渡されます**。

!!! info "音声の文字起こしにメンションは入りません"
    文字起こしのテキストそのものに `@` は入らない設計です（発話の記録は辞書の学習源でもあるため、余計な文字で汚さないようにしています）。音声をエージェントに渡したいときは、この「エージェントに送る」を使ってください。

## 呼び忘れたときは、編集で足せます

送信したあとに「あ、メンションを付け忘れた」と気づいた場合、**その投稿を編集して先頭にメンションを足すだけ**でエージェントが起動します。

- 自分の投稿にだけ有効です
- 新しくメンションを付けたときだけ・**一度きり**動作します（編集を繰り返しても多重に起動しません）

## 最近の指示から再利用する（v0.7.0）

🤖 パネルには **「最近の指示」** が並びます（[#354](https://github.com/gamasenninn/tealus/issues/354)）。過去に自分がエージェント宛てに送ったメッセージが、そのまま再利用できる形で出てきます。

- **登録は不要です。** よく使う指示を事前に登録する仕組みではなく、**過去の自分の投稿**がそのまま候補になります
- **そのルームで・自分が送ったもの**だけが出ます
- **PC** では `/` を押してから `↑` で辿れます（シェルのコマンド履歴と同じ操作感）
- **選んでも送信はされません。** 入力欄に挿入されるだけなので、直してから送れます

### 数字だけが違う指示は 1 つにまとまります

「直近の画像 3 枚で〜」「直近の画像 5 枚で〜」のように**数字だけが違う指示**は 1 件に統合され、**変わる位置だけが選択された状態**で挿入されます（[#358](https://github.com/gamasenninn/tealus/issues/358)）。そのまま送っても意味が通るよう、一覧には前回の具体的な値が表示されます。

!!! info "穴になるのは「実際に変化した位置」だけです"
    単純に「最初の数字を空欄にする」方式ではありません。それだと「2026年7月の買取金額」の**年まで空欄になってしまう**ためです。履歴の中で実際に 2 種類以上の値が現れた位置だけが、置き換え対象になります。

!!! note "フォームへの回答は履歴に出ません"
    フォームの回答（[フォーム](form.md)）は 1 件が長くなりがちで、混ざると履歴が回答文で埋まってしまうため、除外されています（[#357](https://github.com/gamasenninn/tealus/issues/357)）。フォームに「コメントとして返信」した指示は履歴に出ます。

## 呼び出しが届いたかどうか

`@cc-` で始まるプロジェクト別エージェントを呼んだ場合、**「届きました」という受付表示**が数秒だけ出ます（v0.6.0 [#335](https://github.com/gamasenninn/tealus/issues/335)）。

これが出れば、少なくとも呼び出し自体は成立しています。**受付表示が出たのに応答が返ってこない場合**は、呼び出し側ではなくエージェント側（セッションが起きていない等）を疑ってください。
