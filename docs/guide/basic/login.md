# ログイン

## ユーザーIDでログイン

Tealus はユーザーIDとパスワードで認証します。

1. Tealus の URL にアクセス
2. **ユーザーID**を入力
3. **パスワード**を入力
4. 「ログイン」ボタンをタップ

!!! note "初回ログイン"
    管理者からアカウントが発行されていない場合は、管理者に問い合わせてください。

!!! note "最初にパスワードの変更を求められます（v0.12.0）"
    管理者が決めたパスワードのままだと、「**はじめに、パスワードを変えてください**」の画面だけが出ます。いまのパスワードと新しいパスワード（**8 文字以上**）を入れて「変更する」を押すと使い始められます。管理者がパスワードを入れ直したときも同じです。

## ほかのサイトに Tealus でログインする {#sso}

社内のポータルなど、管理者が決めたサイトには、Tealus の ID で入れます（v0.12.0、[#648](https://github.com/gamasenninn/tealus/issues/648)）。

1. 相手のサイトで「Tealus でログイン」を押す
2. Tealus の画面に「Tealus の ID で <サイト名> にログインします。」と出る（ログインしていなければ、先にログイン画面が出ます）
3. 「**<サイト名> にログインする**」を押すと、相手のサイトに戻ってログインできます

!!! warning "自分で開いたページでなければ、押さない"
    この画面は、自分で相手のサイトから来たときだけ使います。覚えのないリンクから開いたときは、押さずに閉じてください。

ゲストの方は使えません。設定は[アプリの通行証と「Tealus でログイン」](../../admin/app-pass.md)を見てください。
