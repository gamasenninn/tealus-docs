# トーク（チャット）

Tealus のメイン機能であるチャットの使い方を説明します。

## メッセージの送信

1. トーク一覧から相手またはグループをタップしてトーク画面を開く
2. 画面下部の入力欄にメッセージを入力
3. **Ctrl+Enter**（Macは Cmd+Enter）で送信

!!! tip "改行と送信"
    **Enter** キーは改行になります。送信は **Ctrl+Enter** です。入力欄は内容に応じて**高さ 120px まで**自動拡張し、それ以上はスクロールします。

!!! note "送れなかったときは、文が入力欄に残ります（[#593](https://github.com/gamasenninn/tealus/issues/593)）"
    サーバーが投稿を断った場合（部屋から外された直後など）は、**入力欄の文を消さずに残し、理由を表示**します。以前は黙って捨てられ、文も消えていました。

## メッセージの受信

メッセージはリアルタイムで配信されます。トーク画面を開いている間は、新しいメッセージが即座に表示されます。

トーク画面を閉じている場合は、トーク一覧に**未読バッジ**（未読数）が表示されます。

## 既読表示

Tealus には2種類の既読表示があります。

- **トーク一覧**: 未読メッセージの数がバッジで表示されます
- **トーク画面**: 各メッセージに既読数が表示されます（例: 既読 3）

トーク画面を開くと、そのルームのメッセージは自動的に既読になります。

## 未読区切り線

前回の閲覧以降に届いた未読メッセージがある場合、「ここから未読」の区切り線が自動で表示されます。どこまで読んだかが一目でわかります。

## リプライ（引用返信）

特定のメッセージに対して返信できます。

1. 返信したいメッセージを**長押し**（PCでは右クリック）
2. コンテキストメニューから「リプライ」を選択
3. 入力欄の上部に引用元メッセージが表示される
4. メッセージを入力して送信

送信されたリプライには、引用元メッセージの内容が吹き出し内に表示されます。

!!! tip "引用部分タップで元メッセージへジャンプ（v0.2.3〜、[#255](https://github.com/gamasenninn/tealus/issues/255)）"
    リプライ吹き出し内の**引用部分をタップ**すると、元のメッセージまでスクロールしてハイライト表示されます。長い議論の流れを遡るのに便利です。

## メッセージの編集

送信済みのメッセージを修正できます。

1. 自分のメッセージを**長押し**（PCでは右クリック）
2. コンテキストメニューから「**メッセージを編集**」を選択
3. テキストを修正して確定

編集されたメッセージには「(編集済み)」の表示が付きます。過去の編集履歴は、メニューの「**編集履歴**」から確認できます。

!!! warning "★ 編集は、既定では使えません"
    **メッセージ編集の既定は「無効」です。** メニューに「メッセージを編集」が出ないときは、故障ではなく設定です。ルーム設定（トーク画面右上の **≡**）の「**メッセージ編集**」で選びます:

    | 設定 | 編集できる人 |
    |---|---|
    | **無効**（既定） | 誰も編集できない |
    | 送信者のみ | 自分が送ったメッセージだけ |
    | メンバー全員 | ルームの誰のメッセージでも |

    ★ 例外として、**文字の入っていない自分の投稿（画像だけ等）には、設定に関係なく「テキストを追加」**で 1 回だけ文章を足せます。以前このページは「デフォルトで自分のメッセージは編集可能」と書いていましたが、誤りでした。

## メッセージの削除

1. 自分のメッセージを**長押し**（PCでは右クリック）
2. コンテキストメニューから「削除」を選択
3. 確認ダイアログで「削除」をタップ

削除されたメッセージは「メッセージが削除されました」と表示されます。他のメンバーのメッセージは削除できません。

!!! note "削除した投稿の添付は開けなくなります"
    削除したメッセージに付いていた画像・動画・ファイルは、**リンクを知っていても開けなくなります**（v0.11.0、[#601](https://github.com/gamasenninn/tealus/issues/601)）。そのメッセージを転送していた先では、転送元の部分が「（元メッセージは削除されました）」と表示されます。

## コンテキストメニュー

メッセージを長押し（PCでは右クリック）すると、以下の操作が表示されます。

| 操作 | 対象 | 説明 |
|---|---|---|
| コピー ／ 部分コピー | テキストのあるメッセージ | 全文、または選んだ部分だけをコピー |
| メッセージを編集 | 設定で許された場合（上記） | 文字のない自分の投稿では「テキストを追加」 |
| 編集履歴 | 編集されたメッセージ | 過去の版を表示 |
| リプライ | すべて | 引用返信 |
| 転送 | すべて | 他のルームへ転送 |
| タグを追加 ／ TODO | すべて | タグを付ける／TODO にする |
| 文字起こしをコピー ／ 部分コピー ／ 編集 ／ 編集履歴 | 音声・動画 | 文字起こしに対する操作 |
| エージェントに送る | 自分のメッセージ（アシスタントのいる部屋） | そのままエージェントへ渡す（[エージェントの呼び出し口](../advanced/agent-entry.md)） |
| お知らせに公開 ／ 非公開 | お知らせ用の部屋のメッセージ | ホームの「お知らせ」に出す／外す |
| 削除 | 自分のメッセージ | メッセージを削除 |

表示される項目は、メッセージの種類・自分の投稿かどうか・ルームの設定・権限によって変わります。

## 吹き出しの全幅展開

AIアシスタントの長文回答など、幅広い内容を読む際に便利な機能です。

- 吹き出しを**ダブルタップ**すると画面幅いっぱいに展開
- もう一度ダブルタップすると元の幅に戻る

## リンクプレビュー

メッセージ内のURLは自動的にリンクプレビュー（OGP）が表示されます。Webページのタイトル・説明・画像がプレビューカードとして表示されます。

## 日付区切りと、日付へ移動

メッセージの間に日付が変わるポイントで「── 4月23日 ──」のような区切り線が自動挿入されます。

画面の一番上には**今見ている日の日付の札が貼り付きます**。札を押すとその月のカレンダーが開き、**投稿のある日を押すと、その日の最初の投稿へ飛びます**（[#476](https://github.com/gamasenninn/tealus/issues/476)）。

## トークを開いたとき

前に開いたときの中身を**先に表示し**、新しい分が届いたら置き換えます（[#600](https://github.com/gamasenninn/tealus/issues/600)）。つながりが遅いときも「何もない画面」で待たされません。

## ログインの期限が切れたら

ログインの期限（7 日）が切れると、**ログイン画面に移ります**（[#539](https://github.com/gamasenninn/tealus/issues/539)）。もう一度ログインしてください。以前は「ルーム一覧の取得に失敗しました」と出るだけで、アプリを閉じて開き直すまで戻れませんでした。

## タイピング表示

相手がメッセージを入力中のとき、「入力中...」の表示がリアルタイムで表示されます。
