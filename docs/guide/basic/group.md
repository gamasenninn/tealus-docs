# グループ

## 1対1トーク

特定のユーザーと1対1でチャットできます。

1. トーク一覧の上部の「**新規作成**」（＋）ボタンをタップ
2. 「**1対1トーク**」を選ぶ（グループなら「グループ作成」）
3. ユーザーを選択
4. 自動的に1対1のダイレクトルームが作成される

!!! note
    同じ相手との1対1ルームは重複して作成されません。既にルームが存在する場合は、そのルームが開きます。

## グループの作成

複数人でチャットするグループを作成できます。

1. トーク一覧画面の「新規作成」ボタンをタップ
2. 「グループ作成」を選択
3. グループ名を入力
4. メンバーを選択
5. 「作成」をタップ

同じ名前のグループがほかにあるときは、作ったあとに「同じ名前のグループがほかに N つあります」と知らせます（作ることはできます。v0.12.0）。

## トーク一覧のタブ {#room-tabs}

トーク一覧は「すべて」「1:1 ルーム」「グループ」のタブで絞り込めます。お客様の部屋がある人には「**お客様**」のタブも出ます（v0.12.0）。

- お客様の部屋とは、管理者が「社外の窓口」の印を付けた口座が作った部屋と、ゲストがいる部屋です（[ユーザー管理 > 社外の窓口](../../admin/user-management.md#external-contact)）
- 窓口の部屋は「お客様」のタブにだけ出ます。ゲストのいる部屋は、ほかのタブにも出ます
- タブの数字は、未読のある部屋の数です
- 選んだタブは端末ごとに覚えます

## 単独グループ（メモ機能）

自分だけのグループを作成すると、個人メモとして活用できます。メンバーを選択せずにグループを作成してください。

## グループ名・アイコンの変更

グループ管理者は、グループ名やアイコン画像を変更できます（システム管理者も、どのグループでも同じ操作ができます。v0.12.0）。

1. トーク画面**右上の ≡** をタップしてルーム設定を開く（1:1 のトークにも ≡ があり、通知などの個人設定を変えられます）
2. グループ名を編集、またはアイコン画像をアップロード

## メンバー管理

グループ管理者は以下の操作が可能です。

| 操作 | 説明 |
|---|---|
| メンバー追加 | 新しいメンバーをグループに招待 |
| メンバー除外 | メンバーをグループから除外 |
| 管理者変更 | 他のメンバーに管理者権限を付与 |

一般メンバーは、自分自身の**退会**のみ可能です。メンバーの追加はグループの全メンバーが行えます。

操作が行われると、トーク内にシステムメッセージが自動投稿されます（「A が B を追加しました」「A が退会しました」「A が B を退会させました」「A が B をグループ管理者にしました」など。主語は操作した人）。

### 除外後の動作

- 除外されたメンバーは**メッセージ履歴にアクセスできなくなります**
- 除外されたメンバーを**再招待することは可能**です

### 退会の制限

グループに管理者が1人しかいない場合、他のメンバーが残っている状態ではその管理者は退会できません。退会する前に、他のメンバーに管理者権限を移譲してください。

## グループの削除

**メンバーが自分 1 人だけになったとき**に削除できます（作成者でなくても構いません。v0.12.0、[#643](https://github.com/gamasenninn/tealus/issues/643)）。システム管理者は、メンバーが残っていても削除できます（確認で残っている人数が出ます）。

1. トーク画面右上の **≡** → メンバー一覧を開く
2. 「**このグループを削除**」をタップ
3. 確認ダイアログで削除

!!! danger "メッセージもすべて消え、元に戻せません"
    削除すると、グループのメッセージと添付ファイルもすべて消えます。

!!! note
    以前このページには「グループの削除機能はありません」と書いていましたが、**誤りでした**。他のメンバーが残っている間は削除ボタンは出ません（システム管理者を除く）。全員が退会したあとに、残った 1 人が削除する順番になります。
