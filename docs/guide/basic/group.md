# グループ

## 1対1トーク

特定のユーザーと1対1でチャットできます。

1. トーク一覧画面の「新規作成」ボタンをタップ
2. ユーザーを選択
3. 自動的に1対1のダイレクトルームが作成される

!!! note
    同じ相手との1対1ルームは重複して作成されません。既にルームが存在する場合は、そのルームが開きます。

## グループの作成

複数人でチャットするグループを作成できます。

1. トーク一覧画面の「新規作成」ボタンをタップ
2. 「グループ作成」を選択
3. グループ名を入力
4. メンバーを選択
5. 「作成」をタップ

## 単独グループ（メモ機能）

自分だけのグループを作成すると、個人メモとして活用できます。メンバーを選択せずにグループを作成してください。

## グループ名・アイコンの変更

グループ管理者は、グループ名やアイコン画像を変更できます。

1. トーク画面**右上の ≡** をタップしてルーム設定を開く（1:1 のトークにも ≡ があり、通知などの個人設定を変えられます）
2. グループ名を編集、またはアイコン画像をアップロード

## メンバー管理

グループ管理者は以下の操作が可能です。

| 操作 | 説明 |
|---|---|
| メンバー追加 | 新しいメンバーをグループに招待 |
| メンバー除外 | メンバーをグループから除外 |
| 管理者変更 | 他のメンバーに管理者権限を付与 |

一般メンバーは、自分自身の**退会**のみ可能です。メンバーの追加はグループの全メンバーが行えます。

操作が行われると、トーク内にシステムメッセージ（「○○さんが参加しました」等）が自動投稿されます。

### 除外後の動作

- 除外されたメンバーは**メッセージ履歴にアクセスできなくなります**
- 除外されたメンバーを**再招待することは可能**です

### 退会の制限

グループに管理者が1人しかいない場合、他のメンバーが残っている状態ではその管理者は退会できません。退会する前に、他のメンバーに管理者権限を移譲してください。

## グループの削除

**グループの作成者で、メンバーが自分 1 人だけになったとき**に削除できます。

1. トーク画面右上の **≡** → メンバー一覧を開く
2. 「**このグループを削除**」をタップ
3. 確認ダイアログで削除

!!! danger "メッセージもすべて消え、元に戻せません"
    削除すると、グループのメッセージと添付ファイルもすべて消えます。

!!! note
    以前このページには「グループの削除機能はありません」と書いていましたが、**誤りでした**。他のメンバーが残っている間は削除ボタンは出ません（全員が退会したあとに作成者が削除する、という順番になります）。
