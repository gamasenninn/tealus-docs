# 音声メッセージ

テキストの代わりに音声でメッセージを送信できます。送信された音声は自動で文字起こし・AI整形されます。

## 録音と送信

1. 入力欄の **マイクボタン** をタップ
2. ボトムシートが表示され、録音が開始される
3. 録音中はタイマーと波形が表示される
4. 「送信」をタップして送信、または「キャンセル」で取り消し

!!! tip
    チャット画面はそのまま表示されるため、録音しながらメッセージを確認できます。

## 再生

送信された音声メッセージは吹き出し内に再生バーとして表示されます。

- **▶ ボタン** をタップして再生
- 再生バーで再生位置を変更可能

## 文字起こし（gpt-4o-mini-transcribe + AI整形）

音声メッセージ送信後、以下の処理が自動的に実行されます。

1. **音声文字起こし**: OpenAI の音声認識 API による文字起こし（v0.2.4〜 default は **`gpt-4o-mini-transcribe`** + 業務辞書 inject、環境変数 `WHISPER_MODEL` で `gpt-4o-transcribe` / `whisper-1` への切替可、「処理中...」と表示）
2. **AI整形**: 文字起こし結果を読みやすい文章に整形（「AIが文章を整えています...」と表示）

整形された文字起こしテキストは、音声の吹き出しの下に表示されます。

!!! tip "業務辞書 inject による業界用語認識（v0.2.4〜、[#269](https://github.com/gamasenninn/tealus/issues/269) Phase 2）"
    v0.2.4 で default model が `gpt-4o-transcribe` → **`gpt-4o-mini-transcribe`** に切替、業務辞書（vocabulary）を文字起こしのプロンプトに渡す **model-aware vocabulary inject** が稼働します。業界用語・固有名詞・短人名の認識精度が向上します（業務無線 dogfood の業界用語 + 短人名 6/6 完璧 verify）。

    辞書の語は、**データベースの業務辞書（`dictionary` テーブル）**から読みます（[#327](https://github.com/gamasenninn/tealus/issues/327)。テーブルが空のときだけ `transcription_guideline.json` の語を使います）。辞書は使われ方から育ちます（[業務辞書](../../admin/dictionary.md)）。organon を使う環境では、整形の段で organon の知識も渡します。

!!! info "文字起こしの経路は 3 つから選べます（[#424](https://github.com/gamasenninn/tealus/issues/424)）"
    管理者が `STT_BACKEND` で選びます: `openai`（既定）／ `local`（自ホストの Qwen3-ASR）／ `gemini`（辞書の語を音声認識の段で渡せる。固有名詞の正答が 50% → 85% に上がった実測あり）。local / gemini が失敗したときは openai に切り替わります。

!!! info "動画/音声 文字起こしツール（v0.2.4〜、[#271](https://github.com/gamasenninn/tealus/issues/271)）"
    Tealus に投稿した **動画メッセージ** も AI エージェントから文字起こしできるようになりました（`transcribe_media` MCP tool、tealus-mcp v0.13.0）。10MB を超える動画も server-side で ffmpeg `-vn` audio 抽出 → Whisper API のフローで処理、抽出した text はキャッシュされて再呼び出し時は即時返却されます。詳細は [MCP Server](../../dev/mcp.md) の `transcribe_media` を参照。

## 文字起こしの編集

文字起こし結果を手動で修正できます。

1. 音声メッセージの「文字起こしを編集」ボタンをタップ（自分の音声。部屋の「文字起こし編集」が「メンバー全員」なら他の人の音声も）
2. テキストエリアで内容を修正
3. 確定ボタンを押す

編集した内容はリアルタイムで全メンバーに反映されます。

!!! tip "音声を聴きながら編集（v0.2.3〜、[#248](https://github.com/gamasenninn/tealus/issues/248)）"
    編集 modal 内に**音声再生スライダー**が組み込まれており、原音を聴きながら文字起こしを修正できます。聞き取りにくい箇所のシークがしやすく、特に長尺の voice メッセージで効果的です。

!!! tip "連続編集 — 前/次ボタンで隣の音声へ送る（[#302](https://github.com/gamasenninn/tealus/issues/302)）"
    編集画面の **「前/次」ボタン** で、隣の音声メッセージへ送って続けて編集できます。直した内容は保存してから移ります（直していなければ保存しません）。

!!! tip "時刻タグから音声へ飛ぶ（[#398](https://github.com/gamasenninn/tealus/issues/398)）"
    通話の録音など、**音声が添付された投稿の編集画面**では、本文に `[1:23]` のような時刻タグがある場合、テキスト欄の外に**タグがチップとして並び**、押すとその位置へ再生が飛びます。端には **10 秒戻し／10 秒送り**のボタンがあります。

### キーボード操作（PC、[#604](https://github.com/gamasenninn/tealus/issues/604)）

| キー | 動き |
|---|---|
| **Alt + ← / →** | 前 / 次の音声へ（保存してから移る） |
| **Ctrl + Enter** | 確定 |
| **Esc** | 戻る（閉じる） |
| **Ctrl + Space** | 再生 / 一時停止 |
| **Alt + , / Alt + .** | 10 秒戻す / 10 秒送る（日本語入力がオンでも効く） |
| ← / →、Space | テキスト欄の外にいるとき: 前 / 次、再生 / 一時停止 |

日本語の変換中のキーは拾いません。PC ではボタンにキーの案内が出ます。Ctrl + Space と Alt + , / . は、音声が添付された投稿（通話の録音など）の編集画面でも使えます。

### 編集履歴

過去の編集内容は「履歴ボタン」からバージョン管理で確認できます。

!!! note "編集権限"
    文字起こしの編集は、既定では**送信者のみ**です。部屋の管理者がルーム設定の「**文字起こし編集**」を「メンバー全員」にすると、誰でも直せます（本文の「メッセージ編集」とは別の設定です）。

## 再文字起こし

文字起こしが失敗した（`status=error`）場合や、結果が不適切な場合に、**手動で retry** できます（v0.2.2〜、[#216](https://github.com/gamasenninn/tealus/issues/216)）。

1. 音声メッセージの「再文字起こし」ボタンをタップ（自分の音声。部屋の「文字起こし編集」が「メンバー全員」なら他の人の音声も）
2. 確認ダイアログで OK
3. 新しいバージョンの文字起こしが生成され、Socket.IO 経由でリアルタイムに UI が更新される

| voice の状態 | ボタンの位置 |
|---|---|
| `status=error`（失敗） | prominent（目立つ位置に配置） |
| `status=done`（成功済） | 「編集」「履歴」と並ぶ |

!!! note "新 version として保存"
    再文字起こしは編集と同じく**新しい version を作成**するため、過去の結果は履歴ボタンから確認できます（破壊的に上書きされません）。

## 連続再生

複数の音声メッセージを連続して再生できます。

1. ルーム設定画面 → 「個人設定」→「音声の連続再生」をONにする
2. 音声メッセージを再生すると、再生完了後に次の音声メッセージが自動で再生される
3. 再生中のメッセージは自動スクロールで画面中央に表示される

停止するには、再生中の一時停止ボタンを押してください。

## AI回答の読み上げ（TTS）

AIエージェントの回答を、端末のスピーカーから音声で自動読み上げできます。

### 有効化

1. プロフィール設定を開く
2. 「AI回答の読み上げ」をONにする

### 動作の流れ

1. AI の回答がテキストで表示される
2. 同時に、**その端末のスピーカーから回答が読み上げられる**
    - サーバー側で音声合成（Aivis / OpenAI / Gemini）を設定している場合は、その音声を再生
    - 未設定の場合は、端末のブラウザ標準音声（Web Speech API）で発声

!!! note "トランシーバーには接続しません"
    以前このページには「送信するとトランシーバーが自動接続され、30 秒で自動切断される」と書いていましたが、**誤りでした**。読み上げはトランシーバーとは別の経路で届きます。トランシーバーは、トーク画面上部の電波アイコンで自分で接続するものです（[音声・ビデオ通話](../advanced/call.md)）。

!!! tip
    画面を見なくてもAIの回答を聞けるため、作業中のハンズフリー運用に便利です。

読み上げのエンジンと声は、トーク画面右上の **≡** → ルーム設定の「**読み上げエンジン**」「**声**」で部屋ごとに変えられます（1:1 は本人、グループは部屋の管理者）。詳しくは [TTS 読み上げ](../advanced/tts.md) を参照してください。

## 音声リプライ

音声メッセージでもリプライ（引用返信）が可能です。リプライされた音声メッセージには、引用元のテキスト（文字起こし含む）が表示されます。
