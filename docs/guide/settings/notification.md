# 通知設定

## プッシュ通知

Tealus はPWAのService Workerを利用したプッシュ通知に対応しています。

### 通知の有効化

初回利用時にブラウザから通知許可を求められます。「許可」を選択するとプッシュ通知が有効になります。

### 通知されるイベント

- 新着メッセージ
- メンション（`@名前`）
- 通話の着信

### 通知が来ないとき（意図した動き）

| 場面 | 理由 |
|---|---|
| **その部屋をいま開いて見ている** | 見ている部屋には鳴らしません（[#475](https://github.com/gamasenninn/tealus/issues/475)）。画面が裏に回ると、また届きます |
| **その部屋の通知をオフにしている** | 下記「ルームごとの通知」 |
| **機械（AI・Bot）の投稿** | 既定では鳴らしません。部屋の管理者が「機械の投稿の通知」を「鳴らす」にすると届きます（[#463](https://github.com/gamasenninn/tealus/issues/463)） |

### 通知をタップすると

その部屋が開きます。すでに Tealus を開いている窓があれば、その窓で移ります（[#544](https://github.com/gamasenninn/tealus/issues/544)）。

### 通知が届かない端末

この端末に通知の宛先が無い場合（iPhone で許可をやり直したときなど）、プロフィールに「**この端末で通知を受け取る**」ボタンが出ます。押して登録し直してください（[#546](https://github.com/gamasenninn/tealus/issues/546)）。

## ルームごとの通知（[#463](https://github.com/gamasenninn/tealus/issues/463)）

トーク画面右上の **≡** → 「**このルームの通知**」で、部屋ごとにオン / オフできます（自分の分だけ。1:1 のトークにもあります）。オフにすると、プッシュ通知も画面の中の通知音も止まります。

部屋の管理者は、ルーム設定（管理者）の「**機械の投稿の通知**」で、AI・Bot の投稿でも鳴らすかを選べます（既定は鳴らさない）。各自が「このルームの通知」をオフにしていれば、そちらが優先します。

## ホーム画面アイコンの未読バッジ（PWA App Badge、v0.2.4〜）

PWA としてホーム画面に追加している場合、**ホーム画面アイコンに未読件数のバッジが表示**されます。Tealus を開かなくても、未読の有無と件数が一目で分かります。

!!! info "対応環境"
    OS / ブラウザの App Badge API 対応状況に依存します。

    - **iOS / iPadOS**: Safari + ホーム画面に追加した PWA で対応
    - **Android**: Chrome + ホーム画面に追加した PWA で対応
    - **デスクトップ（macOS / Windows）**: Chrome / Edge でインストールした PWA で対応

    非対応環境では、バッジは表示されませんが他の通知機能（プッシュ通知 / 通知音）は通常通り動作します。

### 動作の概要

1. Tealus を開いていない時に未読メッセージが届く
2. Service Worker が未読件数を OS にレポート
3. ホーム画面アイコンの右上に数字バッジが出現
4. Tealus を開いて既読化するとバッジは自動で消える

## 通知音

新しいメッセージを受信すると通知音が鳴ります。プロフィールの「**メッセージ受信時に通知音を鳴らす**」で切り替えます。

- **アカウントごとの設定**です。どの端末で切り替えても、**すべての端末に効きます**（[#516](https://github.com/gamasenninn/tealus/issues/516)）
- 切っても**プッシュ通知は届きます**（音だけ鳴らなくなります）。Android では画面の上に帯が出ず、通知の欄に静かに入ります（[#518](https://github.com/gamasenninn/tealus/issues/518)）
- **通話の着信は鳴ります**
