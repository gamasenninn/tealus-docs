# アプリの更新

Tealus は PWA（ホーム画面に追加して使えるアプリ）として動きます。サーバー側が新しい版に更新されたとき、**端末側のアプリも新しくする必要があります**。

v0.7.0（[#355](https://github.com/gamasenninn/tealus/issues/355) / [#356](https://github.com/gamasenninn/tealus/issues/356)）から、アプリが**自分が古くなったことに気づいて更新を促す**ようになりました。

## 更新バナー

アプリが新しい版の存在に気づくと、更新を促すバナーが表示されます。バナーから更新すると、古いキャッシュを捨てて読み込み直します。

気づく契機は次のとおりです。

- アプリの起動時
- **他のアプリから戻ってきたとき（前面復帰）**
- 一定時間ごと（30 分間隔）

!!! info "iOS の PWA では「前面復帰」が主な契機です"
    ホーム画面から起動した iOS の PWA は、アプリを閉じずに放置しても画面遷移が起きないため、**別のアプリから戻ってきたタイミング**が実質的な検知の契機になります。

!!! note "確信が持てないときはバナーを出しません"
    新旧の判定材料が揃わない場合、バナーは表示されません。**間違ったバナーが出っぱなしになる方が有害**という判断です。この場合でも、下記のビルド ID で手動確認できます。

## 自分の版を確認する（ビルド ID）

**プロフィール画面の下部にビルド ID が常時表示されています。**

実機が新旧どちらの版なのかを目視で確かめられる唯一の手段です。「更新したはずなのに直っていない」というときは、まずここを確認してください。

## それでも更新されないとき

プロフィール画面の **「キャッシュをクリア」** を実行してください。保存された古いファイルを捨てて読み込み直します。

PWA として使っている場合は、**アプリをいったん閉じてから開き直す**のも有効です。

!!! warning "自己ホスト運用の場合"
    サーバーを新しい版に更新したのに端末に届かない場合、**クライアントの再ビルド（`npm run build`）が済んでいない**可能性があります。また、リバースプロキシを挟んでいる環境では、プロキシ側のキャッシュ設定が更新の妨げになることがあります。

    バージョンを上げる際の具体的な手順と注意点は、本体リポジトリの [アップグレードガイド](https://github.com/gamasenninn/tealus/blob/main/docs/upgrade-guide.md) にまとまっています。
