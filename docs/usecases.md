# ユースケース集

Tealus の多様な活用シーンを紹介します。「自分ならこう使える」をイメージしてみてください。

## 現場・フィールドワーク

端末を手に持てない状況でも、音声とAIで業務を支援します。

**建設現場の音声指示**
現場監督が音声で AI に質問し、音声で回答を受け取る。図面の確認や安全基準の問い合わせを、画面を見ずに。
`音声メッセージ` `会話モード` `TTS読み上げ` `AI`

!!! note "声で AI に聞くときの条件"
    - 音声メッセージ（トランシーバー接続中に話した分も含む）は文字起こしされ、その文が AI に渡ります。ただし **3 人以上の部屋では、先頭に `@アシスタント` が要ります**。声には `@` が乗らないので、**AI と 1 対 1 の部屋**で使うか、部屋の応答モードを「全応答」にしてください（管理者がダッシュボードのルーム設定で変更、[ダッシュボード](admin/dashboard.md)）
    - 声で往復したいときは、部屋の管理者が開けた部屋で**会話モード**（押しながら話す方式、[会話モード](guide/advanced/voice-chat.md)）が使えます
    - 回答の読み上げは、各端末のスピーカーから流れます（トランシーバーの音声には乗りません）

**倉庫の在庫確認**
「A棚に○○はある？」と音声で聞くと、AI が在庫データを調べて音声で回答。端末を手に持てない状況でも使える。
`音声メッセージ` `文字起こし` `AI` `TTS読み上げ`

**イベント運営のスタッフ連絡**
会場内の全スタッフにトランシーバーで一斉連絡。無線機の購入・管理が不要。スマホだけで完結。
`トランシーバー` `グループ`

**農業の作業記録**
畑で音声メモを送信。自動文字起こしで作業記録が残る。手が汚れていてもスマホを触らずに記録可能。
`音声メッセージ` `文字起こし`

**配送ドライバーの運行連絡**
運転中はトランシーバーで報告、事務所はテキストで確認。話した分は音声メッセージとしても投稿され、自動で文字起こしされるので記録も残る。
`トランシーバー` `文字起こし`

## 小規模企業・チーム

コスト削減と業務効率化を同時に実現します。

**Slack/Teams の代替（コスト削減）**
50人で Slack 月5万円、Teams 月3万円。Tealus なら NAS 1台で月額ゼロ円。チャット、通話、AI まで全部入り。
`チャット` `通話` `自前ホスティング`

**社内ナレッジベース**
「前回の○○の件どうなった？」と AI に聞くと、過去の会話履歴から該当する議論を見つけて回答。議事録いらず。
`AI` `MCP` `検索`

**業務日報の自動化**
一日の終わりに AI が業務メモの会話をサマリーして日報を自動生成。人間は確認して送信するだけ。
`AI` `MCP`

**朝礼・終礼の議事録自動化**
グループ通話で朝礼・終礼を実施。録画映像を自動文字起こしし、AI が要点を整理して議事録を生成。会議の記録が自動で残る。
`グループ通話` `文字起こし` `AI`

**新人教育**
新人が AI に業務手順を質問。声で回答を聞きながら作業できるので、先輩社員の手を止めない。
`AI` `TTS読み上げ`

**多拠点の朝礼**
本社と支店をグループ通話でつなぐ。録音なしの気軽な通話で、毎朝の情報共有がスムーズに。
`グループ通話`

## 個人・クリエイター

1人でも AI チームを持てます。

**個人の AI 秘書**
DM で AI にスケジュール確認、調べ物、文章校正を依頼。音声で回答を聞きながら家事や移動中に使える。
`AI` `DM` `TTS読み上げ`

**個人の AI 組織**
複数の AI エージェントにそれぞれ専門分野（経理、マーケティング、技術）を持たせてチームを作る。1人で会社を回す。
`複数エージェント` `ルーム設定`

**ブログ/SNS 記事の下書き**
AI に指示して記事を書かせ、TTS で読み上げてもらいながら推敲。耳で聞くと文章の違和感に気づきやすい。
`AI` `TTS読み上げ`

**アイデアの音声メモ**
思いついたらすぐ音声で送信。自動文字起こしで後から全文検索可能。ボイスレコーダーより便利。
`音声メッセージ` `文字起こし` `検索`

**語学学習**
AI に外国語で話しかけ、TTS で発音を確認。部屋ごとに読み上げのエンジン（Aivis / OpenAI / Gemini）と声を変えれば、異なる話者の発音も聞ける。
`AI` `TTS読み上げ` `音声モデル選択`

## 開発チーム

AI と人間が対等に協働する開発体験。

**AI ペアプログラミング**
コードの相談をチャットで、AI の回答を音声で聞きながらコーディング。画面を切り替えずに済む。
`AI (Deep Agent)` `TTS読み上げ`

**Claude Code との連携で開発体験が変わる**
Claude Code でのコーディング中に、タスク完了やエラーを hooks から Tealus の部屋へ投稿。テストが通った、ビルドが完了した、がスマホに届く。逆に部屋から `@cc-{班}` で Claude Code のセッションを起こして作業を頼める。
`Claude hooks` `プッシュ通知` `cc-bridge`

!!! note
    bot（機械）の投稿は、既定ではプッシュ通知を鳴らしません。部屋の管理者がルーム設定の「機械の投稿の通知」を「鳴らす」にしてください（[通知設定](guide/settings/notification.md)）。

**障害対応の即時連絡**
プッシュ通知で障害を検知、グループ通話で対応チームが即座に集合。チャットで状況共有しながら通話で議論。
`プッシュ通知` `グループ通話`

**タスク管理**
TODO タグでタスクを管理。AI に「未完了のタスクは？」と聞けば一覧を返してくれる。
`TODO` `AI` `検索`

**AI どうしの協働**
開発 AI がドキュメント AI に GitHub Issue で作業指示。レビューして承認。人間は最終確認だけ。
`複数エージェント` `GitHub連携`

## セキュリティ重視の組織

**データの置き場所は自社。どの AI に何を渡すかも自社で選べる**通信基盤。

!!! warning "「社外に何も出ない」わけではありません"
    AI の応答・文字起こし・読み上げを使うと、文や音声が OpenAI / Google（Gemini）/ Aivis に送られます。AI を使わなくても、リンクプレビュー（投稿の URL を取りに行く）やプッシュ通知（Apple / Google の配信サービス経由、中身は暗号化）の通信はあります。詳しくは [FAQ > データは社外に出ますか？](faq.md#data-outside) を参照してください。文字起こしは自前の GPU（`STT_BACKEND=local`）、読み上げは端末の標準音声（`TTS_PROVIDER=browser`）を選べます。

**機密情報を扱うチームの連絡**
チャットデータ・添付ファイルの置き場所は自社のサーバー。AI に何を渡すかは設定で選べる。
`自前ホスティング`

**医療機関の院内連絡**
患者情報をクラウドに出さず、医師・看護師間でセキュアに共有。通話も院内ネットワーク内で完結。
`自前ホスティング` `チャット` `通話`

**法律事務所の案件共有**
クライアント情報をセキュアに管理。案件ごとにルームを分け、AI に判例検索を依頼。
`自前ホスティング` `検索` `AI`

**自治体の内部連絡**
住民データを扱う部署の安全な通信手段。庁内 NAS で運用し、AI・プッシュ通知を使わない構成にすれば、外部への通信を最小限にできる。
`自前ホスティング` `グループ`
